このブラウザは対応していません

このツールはFile System Access API(showOpenFilePicker)を使用してJSONファイルに直接読み書きします。現時点ではGoogle ChromeまたはMicrosoft Edgeでのみ動作します。それらのブラウザでこのファイルを開き直してください。

ブックマークファイルに接続

ブックマークを保存するJSONファイルを開くか、新しく作成してください。以降の追加・編集はこのファイルに自動保存されます。

前回接続していたファイル「」に再接続するには許可が必要です。

タグ＝複数付けられる横断ラベル

グループ＝1つだけ選べる置き場所

URLは http:// / https:// / file:/// のいずれかで始まる必要があります。

※ パスワードは平文で保存されます

キーボードショートカット

/
検索ボックスへフォーカス
n
追加パネルの開閉
?
このヘルプの開閉
Esc
ヘルプ → グループ管理 → フォーム → 選択モードの順に閉じる
↑ ↓ ← →
カード間のフォーカス移動
Enter
フォーカス中のカードのURLを開く
e
フォーカス中のカードを編集
Delete
フォーカス中のカードを削除
s
カード一覧へフォーカス
t
タグタブに切り替えてタグ絞り込みナビへフォーカス
g
グループタブに切り替えてグループ絞り込みナビへフォーカス
c
フォーカス中のカードのログインIDをコピー
p
フォーカス中のカードのパスワードをコピー

      データは接続したJSONファイルに直接保存されます(Chrome/Edge限定・File System Access API使用)。
